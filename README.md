One page of world news from Monday, 23 November 2026: six verified stories
from that day — COP31 collapsing without a deal in Antalya, the Cikande
factory fire toll rising to 7 dead and 50 missing, Nepal's PM holding
bilateral talks with Modi in New Delhi, the capture of FBI most-wanted
"El Chapo Isidro" in Sinaloa, tankers hit in the Strait of Hormuz, and
BepiColombo entering orbit around Mercury after an eight-year trip.

The image is drawn entirely by code: `main.ts` (Node 22, standard library
only — its own PNG encoder and its own 5x7 bitmap font, no network, no
external assets) renders the 1024x1024 front page deterministically.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.png` (1024x1024, under 1 MiB). Running it twice
produces byte-identical output.
